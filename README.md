# 🚀 Kael-Freelance Core

### Myanmar's First Freelance Platform 🇲🇲

**📅 Launching July 15, 2026**

---

## 📖 About

**Kael-Freelance Core** is Myanmar's **first-ever Freelance Platform** – a world-class marketplace connecting talented Freelancers with Clients worldwide.

🌐 **Website:** [kaelfreelancecore.qzz.io](https://kaelfreelancecore.qzz.io)

---

## ✨ Features

- 👤 User System (Email Verification)
- 🎭 Freelancer & Client Roles
- 📦 Gig Marketplace
- 📋 Order System (Pending → Completed)
- 🔒 Escrow Payment (Binance P2P Style)
- 💬 Real-time Chat (Socket.io)
- ⭐ Trust Score System
- 🛡️ 8-Layer Scam Protection
- 🧾 Auto Invoice Generation
- 🎯 Pre-Registration System

---

## 🏗️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | HTML5, CSS3, JavaScript |
| Backend | Node.js + Express.js |
| Database | SQLite |
| Real-time | Socket.io |
| Email | Nodemailer + Gmail SMTP |
| Auth | JWT + bcrypt |
| Hosting | Netlify + Railway |
